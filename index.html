RGB 是加色模式 數值愈高，加入的該色光愈強。
(0, 0, 0) 沒有 Red、Green、Blue 光，因此是 Black。
(255, 255, 255) 三種光都達最高強度，合成 White。
#RRGGBB 每兩個十六進制位元分別代表 R、G、B。
Basic 模式使用 0 / 255 示範最典型的加色混合；Explore 模式則讓每個圓由中心向外逐漸變弱，可探索更多 RGB 組合。
